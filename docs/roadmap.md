# Roadmap

## Preview 0：当前阶段

- 完成项目边界和术语；
- 完成Obsidian字段和内容包模板；
- 完成Codex提示词和人工审批门；
- 完成预览结构校验脚本；
- 用UniPert-G2CP文章作为示例入口；
- 不创建公开GitHub仓库。

## Alpha 1：本地可复用

- 增加创建内容包的脚本；
- 增加从Obsidian来源笔记生成简报的辅助命令；
- 增加图片路径、来源链接和主张台账的自动检查；
- 增加Markdown到微信公众号粘贴稿的转换规则；
- 增加一份完整但脱敏的示例包。

## Beta 2：多栏目管理

- 区分医学教学、科研解读、AI实践、原创工具展示等栏目；
- 增加栏目级模板和不同读者画像；
- 增加发布后反馈记录和选题复盘；
- 增加文章版本与修订记录。

## Public 1：公开仓库

只有完成公开前检查并得到用户确认后，才考虑：

- 选择许可证；
- 创建或绑定GitHub仓库；
- 提交和推送；
- 发布Release或GitHub Pages文档站；
- 对外展示示例文章和配图。
