# GitHub公开前检查

## 必须完成

- [ ] README能说明项目用途、适用人群和不适用场景；
- [ ] 目录中的命令与实际文件一致；
- [ ] 已决定许可证；
- [ ] 已处理图片、文章和第三方代码的署名与使用权限；
- [ ] 已完成敏感信息扫描；
- [ ] 没有私人Obsidian路径、Cookie、令牌、API密钥或患者数据；
- [ ] 示例文章已经脱敏并由用户确认可以公开；
- [ ] 医学免责声明和内容边界已写入公开文档；
- [ ] 已区分本地修改、已暂存、已提交、已推送和已发布；
- [ ] 用户明确同意创建或更新GitHub仓库。

## 不能用来替代的证据

- `bash scripts/validate_preview.sh`只能证明预览项目结构和基础规则通过；
- 它不能证明医学内容正确；
- 不能证明版权已经获得；
- 不能证明公众号已发布；
- 不能证明GitHub已公开；
- 不能证明模型输出已经获得专家签署。
