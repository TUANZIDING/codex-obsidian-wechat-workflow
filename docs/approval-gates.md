# Approval gates

## Gate A：范围确认

确认输入来源、目标读者、文章用途和允许的素材范围。未确认时可以阅读和提出方案，但不应大规模改写或生成最终发布包。

## Gate B：角度确认

用户确认标题方向、开头问题、文章主线和不写内容。这个门防止公众号文章从“医学＋AI实践”漂移成泛AI内容。

## Gate C：证据与医学审校

确认关键事实、数字、医学表述、研究局限和免责声明。计算预测不得写成临床证据，示意图不得写成精确解剖或手术模拟。

## Gate D：公开资产确认

确认哪些正文、图片、代码链接和案例可以进入公众号或GitHub。私人素材、患者资料、未公开研究数据和不确定版权的图不能进入公开包。

## Gate E：上传确认

用户确认标题、正文、封面、图片顺序、原文链接和作者信息后，才能生成 `approved` 上传包。

## Gate F：最终发布

微信公众号后台的“发布”是独立动作。Codex可以准备、核对和展示清单，但默认停在发布前，不代替用户点击最终发布。

## Gate G：GitHub公开

创建公开仓库、改变仓库可见性、commit、push、tag或发布Release前，必须再次取得用户明确确认。
