# UniPert-G2CP example integration

这是当前预览项目的公开结构示例，对应一个“从论文来源到科研人员公众号文章”的内容包。仓库只保留工作流说明和主张台账，不把个人 Obsidian 路径、原始文章稿件或未完成的配图包带入公开仓库。

## 示例边界

- `claim-ledger.tsv`：展示如何记录主张、证据状态和发布前检查；
- 本目录不包含原始 Obsidian 笔记；
- 本目录不包含完整公众号文章或论文原图；
- 本目录不把本机绝对路径、个人资料或未公开研究材料写入 Git 历史。

## 这个示例展示的工作流

```text
论文来源笔记
  → 研究问题 / 方法 / 结果 / 局限提取
  → 面向科研人员的公众号结构
  → 无文字科学视觉
  → 数字和证据边界保留在正文
  → 发布前说明“计算预测不等于临床验证”
```

## 公开前的特殊检查

- 原文和 DOI 是否保留准确；
- 论文中的数字是否仍处于原文语境；
- 生成图片是否作为原创辅助视觉而非论文原图使用；
- 文章是否明确区分计算预测、机制线索和实验验证；
- 是否需要公开完整图片、只公开模板，或仅保留结构示例。
